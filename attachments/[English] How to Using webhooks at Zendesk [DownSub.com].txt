You might have heard of them in the past and
wondered what they are, or you might interact
with them on a daily basis.
But, what are webhooks - and how do they work?
At their core, webhooks are a way that you
can send information to a specified URL automatically,
in response to events.
This happens by way of “user-defined HTTP
callbacks”.
All this means is that the user will specify
the content of the payload and the URL that
the content should be sent, and the webhook
will take care of the rest when a specified
event takes place.
Say for example, you have a workflow in Zendesk
where anytime a new ticket is submitted, you’d
like to record the email address of the requester
in an external database.
You can set up a trigger which fires an action
to notify the webhook when a new ticket is
received.
You’d then provide the email address to
the webhook, and that would be sent as a POST
request to the external database.
Webhooks aren’t just limited to POST requests,
either.
There are many different ways you can utilize
webhooks when working with Zendesk, and we’ll
go over some of these here next!
So, how do webhooks work at Zendesk?
Webhooks are used by automations and triggers
in Zendesk Support when a ticket meets specific
conditions.
For example, you could create a webhook to
alert your team in Slack when an urgent ticket
is created.
Or, you could update a card in JIRA with comment
updates received on a ticket in Zendesk.
Creating webhooks in Zendesk is super easy,
whether that be in your Admin Center, or via
the Webhooks API.
After creating the business rules that will
execute the action to notify your webhook,
you simply need to set up the webhook by entering
a name, description and endpoint URL.
Next, you’ll select a request method and
request format.
Lastly, you’ll select the authentication
type required for the request.
And that’s all there is to it!
Your webhook is ready to be associated with
the appropriate automation or trigger.

The Webhook API lets you manage webhooks and
enable subscriptions to receive notifications
about Zendesk events.
As with webhooks created in the Admin Center

One thing to note, the webhooks API is allowed
for users with admin or above level permissions
in your Zendesk account.
If your profile doesn’t have admin or above
permissions, your Zendesk administrator may
be able to help with getting you set up.
